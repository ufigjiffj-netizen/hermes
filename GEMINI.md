# Project Rules

## Style Guide

Before writing or modifying any code, always read and follow the constraints defined in [CONSTRAINTS.md](./CONSTRAINTS.md). Treat it as the authoritative style guide for this project.

Specifically:
- Before starting any coding task, read `CONSTRAINTS.md` to understand current quality thresholds and coding standards.
- All code changes must comply with the constraints defined there.
- Do not weaken, bypass, or ignore any constraint without explicit user approval.
